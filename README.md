# diabetes-prediction
diabetes prediction

I recently did a small Python practice project using a diabetes dataset. With the help of Pandas and NumPy, I first explored the data to understand its structure — like how many rows and columns it had and what kind of values were inside. Then I worked on cleaning the dataset. For example, wherever the data had zeros in places where they didn’t make sense, I replaced them with NaN and later filled those gaps using the median of each column. Doing this gave me a clear idea of how we prepare raw data before using it for machine learning or analysis. Honestly, this project was very helpful for me to learn the basic steps of data preprocessing in a practical way.
